The native DosCreateThread implementation previously discarded its Win32
thread handle immediately. It now retains the handle in a locked table so
DosWaitThread can join a thread even if it exits before the caller waits.
Wait supports a specific TID or zero (any tracked non-self thread), WAIT and
NOWAIT, returns 294 when NOWAIT finds a running thread, and 309 for invalid,
self, or already reaped threads. Invalid parameters return 87. Successful
wait publishes the completed TID and releases the retained handle.
Temporary duplicate handles protect concurrent waiters; a competing reaper
returns invalid-thread rather than closing a reused slot. The table has 64
unreaped thread slots; a full table returns not-enough-memory on creation.
Threads that are never joined retain their slot until process termination.
