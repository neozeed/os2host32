# Microsoft Programmer's Library — OS/2 Reference

This directory contains the OS/2 documentation supplied in the `mspl_v1.3_os2.zip`
reference archive.  The original text files are preserved verbatim under `os2/`.
They are reference material only and are not part of the OS2HOST32 build.

## Project rule

Do not edit these reference texts as part of implementation work.  If annotations,
API notes, or compatibility findings are needed, put them in `docs/notes/` or the
appropriate milestone documentation instead.  This keeps the historical source
material pristine and makes it possible to distinguish Microsoft's documentation
from OS2HOST32 observations and implementation notes.
