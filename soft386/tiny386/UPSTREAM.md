# Tiny386 source lineage

The files in this directory are the Tiny386 i386 CPU core carried forward from
the live-proven Brain-in-a-Jar R1 checkpoint, with the small state-restore delta
documented in `../docs/TINY386-STATE-RESTORE.patch`.

Upstream project: https://github.com/hchunhui/tiny386

Upstream identifies the project and CPU emulator as BSD-3-Clause licensed.
Before publishing or redistributing this source tree outside the research
package, retain/copy the upstream `LICENSE` file alongside these sources.
